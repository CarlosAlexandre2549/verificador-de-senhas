Verificador de Senhas Seguras

Aplicação web desenvolvida com foco em **Cibersegurança** e **Desenvolvimento Front-end** que avalia a força de senhas em tempo real e 
calcula o tempo estimado para quebra por força bruta.

**[Clique aqui para testar o projeto online](https://github.io)**

---

Funcionalidades

- **Análise em tempo real:** Feedback instantâneo a cada caractere digitado.
- **Cálculo de Entropia:** Estima o tempo necessário para um computador moderno quebrar a senha por força bruta.
- **Checklist de Segurança:** Verifica tamanho mínimo, letras maiúsculas, minúsculas, números e símbolos especiais.
- **Visualizar Senha:** Botão prático para mostrar ou ocultar a senha digitada.
- **Privacidade Total:** Todo o processamento acontece localmente no navegador do usuário, sem envio de dados para servidores.

---

Tecnologias Utilizadas

- **HTML5** (Estrutura semântica)
- **CSS3** (Estilização responsiva e tema escuro)
- **JavaScript** (Manipulação de DOM, Expressões Regulares e cálculos matemáticos)
